💡 나이스(NEIS) 양식에 맞추어 시트 열 순서를 바꾸셨어도 100% 정상 작동합니다!
스크립트가 스프레드시트 1행의 제목을 자동 분석하여 선생님께서 배치하신 열 위치에 정확히 기록합니다.

1단계: 구글 시트 연동 코드 (Code.gs) 가져오기 나이스 15개 열 완벽 자동인식

아래 버튼을 눌러 코드를 복사하거나 다운로드한 후, 구글 스프레드시트 [확장 프로그램] → [Apps Script]의 Code.gs에 붙여넣으세요.

2단계: Google Apps Script 웹 앱 배포 URL 등록
스프레드시트 주소(docs.google.com)가 아닌, Apps Script [배포]에서 발급된 "/exec" 주소여야 합니다.
⚠️ "URL을 넣었는데 연동이 안 돼요!" 4가지 핵심 원인과 해결법
  • 1
    [가장 빈번한 원인] 배포 실행자 및 액세스 권한 설정:
    학교/교육청 구글 계정으로 웹 앱을 배포할 때 아래 2가지 설정이 일치하지 않으면 외부 전송이 100% 차단됩니다.
    • 다음 사용자로 실행: 반드시 「나(내 계정 / User managing the script)」로 설정 ('웹 앱에 액세스하는 사용자' 선택 시 인증 오류 발생)
    • 액세스할 수 있는 사용자: 반드시 「모든 사용자(Anyone)」로 설정 (기본값인 '내 조직' 또는 '나만'으로 두면 외부 전송 차단)
  • 2
    [코드 복사 후 필수] [새 버전]으로 배포하기:
    Code.gs 소스코드를 새로 붙여넣고 저장(💾)만 누르면 웹 앱에는 이전 코드가 계속 동작합니다!
    반드시 Apps Script 창 우측 상단 [배포] → [배포 관리] → ✏️수정(연필 아이콘) → 버전: [새 버전(New Version)] 선택 → 하단 [배포]를 눌러주셔야 수정된 최신 코드가 웹 앱에 즉시 적용됩니다.
  • 3
    웹 앱 주소 확인:
    주소 끝이 반드시 /exec여야 합니다. 스프레드시트 본문 주소(/edit)나 개발자 테스트 주소(/dev)는 브라우저 보안상 전송되지 않습니다.
  • 4
    열 제목(1행) 확인:
    나이스 기준에 따라 열 순서를 자유롭게 바꾸셔도 되지만, 1행의 제목에 연번, 질환명, 학년, 반, 번호, 성명, 성별, 발생일 등의 단어가 포함되어 있어야 해당 열을 자동 인식합니다. (빈 시트인 경우 15개 열 헤더를 자동 생성합니다)
